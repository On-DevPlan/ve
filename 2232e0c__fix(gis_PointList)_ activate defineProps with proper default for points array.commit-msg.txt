fix(gis/PointList): activate defineProps with proper default for points array

PointList.vue had defineProps commented out ("ve 源里 props 未使用"),
but the template references `points.length`. At runtime this throws:

  TypeError: Cannot read properties of undefined (reading 'length')
    at Proxy.<anonymous> (PointList.vue:55:20)

because no points prop is declared, so `points` is undefined in template.
Parent ControlPanel passes :points="recordPoints" (a prop from gis.vue),
and the chain works — but only when the prop chain is intact. Adding
defineProps makes it explicit and safe.

Fix: declare `defineProps({ points: { type: Array, default: () => [] } })`
so PointList always has a defined points array.
