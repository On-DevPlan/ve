fix(WorkflowCanvas): rename input type to textInput

VueFlow has built-in node types 'input' and 'output' with default
theme styles (width:150px, blue border). Our 'input' type collided
with this, causing the node to overflow and show a blue box.
Renaming to 'textInput' avoids the conflict.
