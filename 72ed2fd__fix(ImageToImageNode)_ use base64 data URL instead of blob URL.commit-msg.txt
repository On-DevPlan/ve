fix(ImageToImageNode): use base64 data URL instead of blob URL

Blob URLs (blob:localhost/...) are only accessible locally and cannot
be fetched by the API server. Switch to readAsDataURL() so the image
is embedded as a base64 data URL, which works for both preview
display and API requests.
