fix(lockfile): regenerate pnpm-lock.yaml to match monorepo root

Regenerate via `pnpm install --no-frozen-lockfile` against the new root
packageManager (pnpm@9.12.0) and stage the fresh lockfile. No source
package.json change in this commit.
