fix(ci): build showcase before vitest so e2e-perf gate finds dist/component-manifest.json

The showcase's e2e-perf.test.ts is an end-to-end performance gate that reads
dist/component-manifest.json (emitted by vite build via the manifest-generator
plugin). Until now, lint.yml only ran `pnpm install` + `pnpm lint` + `pnpm exec
vitest run`, so on a green branch the suite fails before any test runs:

  FAIL |showcase| __tests__/e2e-perf.test.ts
  Error: dist/component-manifest.json missing.
        Run: pnpm --filter @style-library/showcase exec vite build
  ❯ __tests__/e2e-perf.test.ts:31:13

Add the build step before vitest via the workspace-aware
`pnpm --filter @style-library/showcase build`, matching the README and the
root package.json dev/build/preview scripts.
