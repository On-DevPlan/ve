fix(mount-adapters): adopt <link rel=stylesheet> into ShadowRoot for build mode

Vite dev inlines component CSS as <style> tags; vite build emits separate
.css files loaded via <link rel=stylesheet>. adoptStylesInto only cloned
<style> into Shadow DOM, so build mode had zero component styles in the
ShadowRoot.

Fix: adoptStylesInto now also scans document.head.querySelectorAll('link[rel=stylesheet]')
and clones unmatched <link> elements into ShadowRoot, with the same djb2
fingerprint dedup used by the <style> path.

Also add ref doc: .claude/skills/web-work-flow/references/shadow-dom-build-css-loss.md
