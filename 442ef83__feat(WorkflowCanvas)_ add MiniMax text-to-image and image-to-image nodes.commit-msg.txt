feat(WorkflowCanvas): add MiniMax text-to-image and image-to-image nodes

Add two AI generation node types:
- TextToImageNode: enter prompt, select model/aspect/style, generate images
- ImageToImageNode: upload subject image, enter prompt, transform via API

Both display result thumbnails; click a thumbnail to add an ImageNode
to the canvas. API key and endpoint stored in localStorage and
configured via toolbar 🔐 API button.

Comes with new useImageGen.js composable wrapping the MiniMax
/v1/image_generation endpoint.
