* fix(eslint): upgrade react-hooks 4.6.2 -> 5.2.0 to fix ESLint 9 crash

eslint-plugin-react-hooks@4.6.2 内部调用 ESLint 8 的 `context.getSource()`,
与 ESLint 9 flat config 不兼容。任何 .ts 文件跑过 react-hooks 规则
后,后续文件访问 context.getSource() 会抛 TypeError,导致 `pnpm lint`
整条 CI 全崩。同样的 bug 在 deploy HEAD 上已存在,与 PR #6 无关。

修复:
- 升级 eslint-plugin-react-hooks: ^4.6.0 -> ^5.2.0(官方 5.x 兼容 ESLint 9)
- eslint.config.js:给 apps/showcase/**/*.{ts,tsx} 关掉 react-hooks/rules-of-hooks /
  exhaustive-deps / react-hooks-* 规则。原因:showcase 是 Vue 3 host,*.ts 文件里
  调的是 Vue composables(useXxx 命名撞车 React hooks),react-hooks 规则无法区分,
  原本已在 main.ts bootstrap() -> usePlatform() 处误报。react-refresh/only-export-components
  也关掉以免对 Vue 入口报错。

验证:
- npx eslint . --max-warnings=0  → 0 errors / 0 warnings
